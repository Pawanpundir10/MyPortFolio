Pawan's Portfolio - VS Code Theme
This is my personal portfolio, designed to look and feel like Visual Studio Code. It's built with React and Tailwind CSS, showcasing my projects, skills, and contact information in an interactive, developer-focused interface.

🚀 Getting Started
To get a local copy up and running, follow these simple steps.

Prerequisites
Make sure you have Node.js and npm installed on your machine.

Node.js

Installation
Clone the repo

git clone [https://github.com/your_username/your_repository_name.git](https://github.com/your_username/your_repository_name.git)

Navigate to the project directory

cd your_repository_name

Install NPM packages

npm install

Run the development server

npm run dev

Open http://localhost:5173 (or the port shown in your terminal) to view it in the browser.

🛠️ Technologies Used
React: A JavaScript library for building user interfaces.

Vite: A next-generation frontend tooling that provides a faster and leaner development experience.

Tailwind CSS: A utility-first CSS framework for rapid UI development.

Lucide React: A beautiful and consistent icon toolkit.

EmailJS: A service to send emails directly from client-side JavaScript.
